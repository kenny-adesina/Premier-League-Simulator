## TeamHelper.java

> Instance Variables
- `String team1` : Selected team #1
- `String team2` : Selected team #2
- `int score1` : Amount of goals scored by `team1`.
- `int score2` : Amount of goals scored by `team2`

> Methods

- `selectTeam(int,int);` : Selects 2 teams based on index values given.
- `selectTeam();` : Selects 2 random teams.
- `startMatch();` : Begins the simulation if two teams have been selected.
- More to come

## Simulator.java
- The runner file to be paired with `TeamHelper.java`, can be replaced with a custom runner file.


## Indev
